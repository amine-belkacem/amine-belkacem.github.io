# amine-belkacem.github.io

My portfolio, served by GitHub Pages at <https://amine-belkacem.github.io>.
Version 3: plain HTML, CSS and JavaScript, French and English, built for speed (Lighthouse ≥ 90 in every category on phone).

## What is where

| Path | Content |
|---|---|
| `index.html` | Home page. The hero text between `<!--hero:start-->` and `<!--hero:end-->` is generated by `npm run build`, do not edit it there. |
| `js/data.js` | **All the content**: profile, availability, booking link, analytics code, 24 projects (FR + EN), datasheets (`SHEETS`), reports (`PUBLICATIONS`), articles (`POSTS`), demos (`DEMOS`), path, skills |
| `js/app.js` | Renders the page, animations (GSAP), search and filters, project viewer, command palette (Ctrl K or /), phone tab bar, analytics events |
| `js/src/scene.js` | 3D circuit-board hero (three.js). Bundled into `js/scene.min.js` by `npm run build`. Loaded only after the page is displayed. |
| `js/meta.js` | Generated: "last updated" date and Lighthouse scores shown in the footer |
| `css/style.css` | Home page styles, calm-motion mode, phone layout, print layout used for the PDFs |
| `blog/` | Articles (one HTML page each, English and French in the same page) |
| `demo/` | Live demos: `cpa.html` (AES key byte attack), `bpe.html` (French tokenizer, same ids as the Python package) |
| `cv/` | Printable, text-only CV (readable by applicant tracking systems). No phone number on purpose. |
| `css/page.css`, `js/page.js` | Shared style and language switch for blog, demos and CV |
| `vendor/`, `fonts/` | GSAP 3.12.5 and the three fonts, served from this site (no external CDN) |
| `assets/` | Figures (WebP 960 + 480 px), hero posters, icons, link-preview card |

## Everyday changes

- **Text, a project, a datasheet, an article entry:** edit `js/data.js`, then `npm run build`.
- **Booking button:** paste your Calendly link in `PROFILE.booking` in `js/data.js`.
- **Visit statistics:** create a free GoatCounter site, paste its code in `PROFILE.goatcounter`.
- **New article:** copy a file in `blog/`, change the text, add an entry to `POSTS` in `js/data.js`.
- Bump `?v=3.0` in the HTML files after a big change so returning visitors get the new files.

## Commands (once: `npm install`; needs Google Chrome)

| Command | What it does |
|---|---|
| `npm run build` | bundles the 3D, pre-renders the hero (EN + FR) into `index.html`, stamps the date |
| `npm run poster` | re-captures the hero still images (serve the folder on port 8797 first) |
| `npm run lighthouse` | measures the site (phone + desktop) and stores the scores for the footer |
| `python tools/build_pdf.py` | prints `portfolio-en.pdf` and `portfolio-fr.pdf` from the page |
| `python tools/make_icons.py` | favicon, app icons, manifest, link-preview card |
| `node tools/check_bpe.mjs` | checks that the browser tokenizer gives the Python ids (92 texts) |
| `python -m http.server 8797` | local preview at <http://localhost:8797> |

## Motion

Two modes: **full**, and **calm** (gentle fades, slower 3D, no tilt or custom cursor), chosen automatically when the operating system asks for reduced motion. Visitors can switch with the ✦ button in the header. Without WebGL, the hero shows a still image that slowly breathes.
